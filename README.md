# E-Commerce Data Analysis

This repository contains an **E-Commerce Data Analysis project** completed using Python and Jupyter Notebook. The project focuses on exploring and analyzing an e-commerce purchase dataset to extract useful insights from the data.

## Contents

- **Ecommerce Purchases Exercise.ipynb** – Jupyter Notebook containing data analysis exercises along with their solutions.
- **Ecommerce Purchases.csv** – Dataset containing e-commerce purchase information used for the analysis.

## Project Overview

The project involves analyzing an e-commerce dataset using Python and various data analysis techniques. The exercises cover different aspects of working with real-world data, including data exploration, filtering, calculations, and extracting meaningful information from the dataset.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy

## Analysis Covered

- Exploring the e-commerce dataset
- Understanding data types and dataset structure
- Filtering and selecting data
- Performing calculations and aggregations
- Analyzing customer and purchase information
- Working with CSV data
- Extracting useful insights from the dataset

## Dataset

The project uses an e-commerce purchase dataset stored in CSV format. The dataset is loaded into the Jupyter Notebook and analyzed using Python.

## How to Run

1. Install Python and Jupyter Notebook.
2. Download or clone this repository.
3. Open Jupyter Notebook.
4. Navigate to the project folder.
5. Open the `.ipynb` file.
6. Run the notebook cells to view the exercises, code, and answers.

## Purpose

This project was created to practice **Python-based data analysis** and develop practical skills in working with datasets, using Pandas, and performing exploratory data analysis with Jupyter Notebook.
